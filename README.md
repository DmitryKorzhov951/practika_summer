# БД «Прокат автомобилей» (Вариант №17)

Учебная информационная система на C# / WinForms с базой данных Microsoft SQL Server.

## Структура проекта

```
.
├── Database/                     # SQL-скрипты
│   ├── 01_CreateDatabase.sql     # Создание БД и таблиц
│   ├── 02_SeedData.sql           # Заполнение тестовыми данными
│   └── 03_QueriesAndFilters.sql  # Представления (запросы и фильтры)
├── CarRentalApp/                 # Проект Visual Studio (C#, WinForms)
│   ├── CarRentalApp.csproj
│   ├── App.config                # Строка подключения к SQL Server
│   ├── Program.cs                # Точка входа, запуск формы «Заставка»
│   ├── Db.cs                     # Обёртка над SqlConnection
│   ├── Configs/                  # Метаданные таблиц/запросов/фильтров
│   └── Forms/
│       ├── SplashForm.cs         # Стартовая форма «Заставка»
│       ├── MainForm.cs           # Главная кнопочная форма
│       ├── AboutForm.cs          # «О программе»
│       ├── HistogramForm.cs      # Гистограмма зарплат
│       ├── ReportForm.cs         # Универсальный отчёт
│       ├── PageForm.cs           # «Страница»
│       ├── Tables/               # Ленточные и табличные формы таблиц
│       ├── Queries/              # Формы запросов
│       └── Filters/              # Формы фильтров
└── README.md
```

## Установка и запуск

### 1. Создание БД

Откройте SQL Server Management Studio (или Azure Data Studio) и выполните по очереди:

```
Database\01_CreateDatabase.sql
Database\02_SeedData.sql
Database\03_QueriesAndFilters.sql
```

По умолчанию БД создаётся в инстансе `(localdb)\MSSQLLocalDB`. При необходимости измените имя сервера в `CarRentalApp/App.config`.

### 2. Сборка приложения

Требования:
- Windows 10/11
- Visual Studio 2022 (с компонентом «.NET desktop development»)
- .NET 6.0 SDK (или новее)

Откройте `CarRentalApp/CarRentalApp.csproj` в Visual Studio и нажмите **F5** (или соберите из командной строки):

```
dotnet build  CarRentalApp/CarRentalApp.csproj -c Release
dotnet run --project CarRentalApp/CarRentalApp.csproj
```

### 3. Работа в приложении

1. При запуске показывается форма «Заставка» (закрывается через 3 секунды или по клику).
2. Открывается главная кнопочная форма с двумя вкладками:
   - **Формы** — кнопки для открытия ленточных и табличных форм всех таблиц, запросов, фильтров;
   - **Отчёты** — кнопки для открытия отчётов.
3. В нижней части главной формы — кнопки **Выход**, **О программе**, **Гистограмма зарплат**.
4. Для каждой таблицы доступны:
   - Ленточная форма (редактирование с навигацией, добавление/сохранение/удаление, выпадающие списки для FK);
   - Табличная форма (с сортировкой, поиском и фильтрацией по выбранному полю);
   - Отчёт (карточки с цветовым выделением и рамками).
5. Для каждого запроса/фильтра доступны табличная форма и отчёт.
6. На форме запроса «Отдел кадров» есть кнопка **Гистограмма**, открывающая графическое представление зарплат сотрудников.

## 5. Создание ленточных форм (для таблиц и запросов)

### Описание процесса (пример на форме «Клиенты»)

Ленточная форма «Клиенты» представляет собой окно, отображающее данные таблицы
`Klienty` из базы данных в виде сетки с возможностью добавления, изменения, удаления
и сохранения записей. Форма создаётся по следующим этапам.

**1. Создание класса формы.** В проекте, в папке `Forms`, создан класс
`KlientyForm`, унаследованный от `System.Windows.Forms.Form`. Класс реализован как
`partial`: визуальная раскладка элементов вынесена в файл `KlientyForm.Designer.cs`,
а логика — в файл `KlientyForm.cs`.

**2. Размещение элементов в конструкторе.** В конструкторе формы размещены:

- *Шапка формы* (`Panel`) — содержит изображение-постер (`PictureBox`), полупрозрачную
  плашку с заголовком «КЛИЕНТЫ» (`Label`) и красную акцентную полосу снизу.
- *Сетка данных* (`DataGridView`) с настроенными колонками:
  ФИО, Пол, Дата рождения, Адрес, Телефон, Паспорт.
- *Нижняя панель кнопок* (`Panel`) с шестью кнопками управления:
  «Добавить», «Удалить», «Сохранить», «Табличная», «Отчёт», «Закрыть».

Свойства всех элементов (цвета, шрифты, размеры, выравнивание) заданы в дизайнере
и видны в окне «Свойства».

**3. Привязка данных.** В таблицу `Klienty` подключение выполняется через
`SqlDataAdapter`. Данные загружаются в `DataTable` и связываются с `DataGridView`
через `BindingSource` — таким образом, любое изменение в сетке автоматически
отражается в источнике данных.

**4. Обработчики кнопок.** Каждой кнопке в файле `KlientyForm.cs` назначен
обработчик события `Click`, выполняющий нужное действие
(добавление новой записи, удаление текущей, сохранение изменений в БД,
открытие связанной табличной формы или отчёта, закрытие формы).

## 6. Создание табличных форм (для таблиц и запросов)

### Описание процесса (пример на форме «Клиенты — табличная форма»)

Табличная форма «Клиенты» предназначена для просмотра данных в режиме «только
чтение» с возможностями сортировки, поиска и фильтрации по выбранному полю.
Форма не позволяет редактировать данные напрямую — это отличие от ленточной формы.

**1. Создание класса формы.** В проекте, в папке `Forms`, создан класс
`KlientyGridForm`, унаследованный от `Form`.

**2. Размещение элементов формы.**

- *Шапка формы* — постер таблицы и заголовок «КЛИЕНТЫ — табличная форма».
- *Панель параметров* (`FlowLayoutPanel`) — содержит выпадающий список выбора поля,
  текстовое поле фильтра, кнопки сортировки (▲ и ▼), текстовое поле глобального поиска.
- *Сетка данных* (`DataGridView`) в режиме `ReadOnly = true`, без возможности
  добавления строк.
- *Навигатор записей* (`BindingNavigator`) для перемещения по строкам.
- *Нижняя панель кнопок* с тремя кнопками: «Отчёт», «Поиск», «Закрыть».

**3. Привязка данных.** Данные загружаются одним SQL-запросом с `JOIN`
(чтобы вместо кодов внешних ключей сразу отображались наименования).
Результат помещается в `DataTable` и связывается с `DataGridView` через `BindingSource`.

**4. Сортировка, фильтрация, поиск.** Реализованы через свойства `BindingSource.Sort`
и `BindingSource.Filter` — при изменении значения в комбобоксе / текстовых полях
строится выражение фильтра, и сетка автоматически обновляется.

#### Кнопка «Поиск»


Передаёт фокус на поле поиска и выделяет его содержимое — пользователь сразу

#### Поле «Поиск» (обработчик ввода)

```csharp
_txtSearch.TextChanged += (s, e) => ApplyFilter();

private void ApplyFilter()
{
    string v = _txtSearch.Text.Replace("'", "''");
    var parts = _grid.Columns.Cast<DataGridViewColumn>()
        .Select(c => $"CONVERT([{c.Name}], 'System.String') LIKE '%{v}%'");
    _bs.Filter = "(" + string.Join(" OR ", parts) + ")";
}
```

При вводе строится фильтр, который ищет введённое значение во всех колонках сетки.

#### Кнопки сортировки «▲» и «▼»

```csharp
btnSortAsc.Click  += (s, e) => Sort(true);
btnSortDesc.Click += (s, e) => Sort(false);

private void Sort(bool asc)
{
    string col = _cmbField.SelectedItem.ToString();
    _bs.Sort = $"[{col}] " + (asc ? "ASC" : "DESC");
}
```

Сортируют записи по выбранному в комбобоксе полю — по возрастанию или убыванию.

#### Фильтр по выбранному полю

```csharp
_txtFilter.TextChanged += (s, e) => ApplyFieldFilter();

private void ApplyFieldFilter()
{
    string col = _cmbField.SelectedItem.ToString();
    string val = _txtFilter.Text.Replace("'", "''");
    _bs.Filter = $"CONVERT([{col}], 'System.String') LIKE '%{val}%'";
}
```

Фильтрует записи по содержимому конкретного поля, выбранного в комбобоксе.
